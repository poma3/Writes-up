# Eavesdrop

- kiểm tra tcp.tream 0 thì thu được đoạn hội thoại này

![image.png](Eavesdrop/image.png)

- nôm na là client hỏi server cách giải mã tệp tin này, server gửi lệnh giải mã bằng des3, sau đó client yêu cầu server gửi lại file qua port 9002.
- mình sẽ lọc [tcp.](http://tcp.stream)port == 9002

![image.png](Eavesdrop/image%201.png)

- folow tcp stream và chuyển chuỗi đó sang raw rồi lưu lại với tên file là file.des3

![image.png](Eavesdrop/image%202.png)

- chạy lệnh giải mã
    
    ```jsx
    ┌──(phong㉿kali)-[~/Downloads]
    └─$ openssl des3 -d -salt -in file.des3 -out file.txt -k supersecretpassword123
    
    *** WARNING : deprecated key derivation used.
    Using -iter or -pbkdf2 would be better.
                                                                                                                                                             
    ┌──(phong㉿kali)-[~/Downloads]
    └─$ cat file.txt 
    picoCTF{nc_73115_411_5786acc3}                                                                             
    ```
