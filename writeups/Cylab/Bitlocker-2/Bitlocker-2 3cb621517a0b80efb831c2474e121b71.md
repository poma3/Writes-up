# Bitlocker-2

- dùng volatility3 để trích xuất khóa fvek của bitlocker từ bộ nhớ
    
    ![image.png](Bitlocker-2/image.png)
    
- nó trích xuất được ra rất nhiều khóa, nhưng khóa cuối cùng với PoolTag là None và có khóa Tweak mới là khóa mình cần.
- dùng dislocker để mở khóa và lưu vào /mnt/bitlocker
    
    ```jsx
    ┌──(phong㉿kali)-[~/Downloads]
    └─$ sudo mkdir -p /mnt/bitlocker
    sudo dislocker -V bitlocker-2.dd -k  0x8087865bead0-Dislocker.fvek -- /mnt/bitlocker
    ```
    
- tạo folder mới để mount vào file này rồi truy cập file flag.txt để lấy flag
    
    ```jsx
    ┌──(phong㉿kali)-[~/Downloads]
    └─$ sudo file /mnt/bitlocker/dislocker-file
    /mnt/bitlocker/dislocker-file: DOS/MBR boot sector, code offset 0x52+2, OEM-ID "NTFS    ", sectors/cluster 8, Media descriptor 0xf8, sectors/track 63, heads 255, hidden sectors 41531392, dos < 4.0 BootSector (0x80), FAT (1Y bit by descriptor); NTFS, sectors/track 63, sectors 262143, $MFT start cluster 16981, $MFTMirror start cluster 2, bytes/RecordSegment 2^(-1*246), clusters/index block 1, serial number 0ec6ee03e6ee002e6; contains bootstrap BOOTMGR
    
    ┌──(phong㉿kali)-[~/Downloads]
    └─$ sudo mount -t ntfs-3g -o loop,ro /mnt/bitlocker/dislocker-file /mnt/mountbitlocker
    
    ┌──(phong㉿kali)-[~/Downloads]
    └─$ cd /mnt/mountbitlocker
    
    ┌──(phong㉿kali)-[/mnt/mountbitlocker]
    └─$ ls
    '$RECYCLE.BIN'   flag.txt  'System Volume Information'
    
    ┌──(phong㉿kali)-[/mnt/mountbitlocker]
    └─$ cat flag.txt
    picoCTF{B1tl0ck3r_dr1v3_d3crypt3d_9029ae5b}                                                                                                                                                                      
    ```
