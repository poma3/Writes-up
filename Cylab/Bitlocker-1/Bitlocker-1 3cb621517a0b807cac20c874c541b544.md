# Bitlocker-1

- dùng bitlocker2john để trích xuất các key hash trong file .dd và lưu vào file hash.txt
    
    ```jsx
    bitlocker2john -i bitlocker-1.dd > hash.txt
    ```
    
- sau khi có file hash thì dùng john the ripper để crack file hash này, sử dụng wordlist rockyou.txt
    
    ```jsx
    john hash.txt --wordlist=/usr/share/wordlists/rockyou.txt
    ```
    
- tìm được password
    
    ![image.png](Bitlocker-1/image.png)
    
- tạo một folder mới và dùng dislocker với password tìm được để mở khóa file .dd vào thư mục đó
    
    ```jsx
    sudo mkdir -p /mnt/bitlocker
    sudo dislocker -V bitlocker-1.dd -u”jacqueline” — /mnt/bitlocker
    ```
    
- tạo một folder để mount file dislocker vừa được tạo
    
    ```jsx
    sudo mkdir -p /mnt/mountbitlocker
    sudo mount -o loop /mnt/bitlocker/dislocker-file /mnt/mountbitlocker
    ```
    

![image.png](Bitlocker-1/image%201.png)

- clean up
    
    ```jsx
    sudo umount /mnt/mountbitlocker
    sudo umount /mnt/bitlocker
    sudo rmdir /mnt/mountbitlocker
    sudo rmdir /mnt/bitlocker
    ```
